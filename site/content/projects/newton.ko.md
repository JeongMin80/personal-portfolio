> **한 줄 소개**: 하늘에서 떨어지는 사과를 펭귄 플레이어가 피하며 버티는 2D 생존 게임입니다. Holysoft Studios에서 게임 개발을 배우는 시간에 Unity와 C#으로 혼자 만들었고, 아직 완성 전이라 추후에 내용을 추가할 예정입니다.

## 활동 목적

인턴십에서 배운 Unity 기초를 직접 활용해 게임 1개를 만들어 보는 것이 목표였습니다. 구체적으로는 시작부터 게임오버까지 한 판을 플레이할 수 있는 상태로 만들어보는 것을 기준으로 잡았습니다.

개발 기간이 약 1주로 짧았기 때문에 기간 안에 끝낼 수 있으면서도 배운 기능(캐릭터 이동, 오브젝트 생성, 충돌 처리)을 모두 써 볼 수 있는 “떨어지는 사과 피하기”를 주제로 골랐습니다.

## 역할과 기여 범위

- **기획**: 게임 규칙을 “떨어지는 사과를 피해 오래 버티기”로 정하고, 사과가 떨어지는 게임이라는 점에서 뉴턴의 사과를 떠올려 이름을 Newton으로 지었습니다. 플레이어 캐릭터는 펭귄, 장애물은 사과로 정했고, 사과 스킨을 바꿀 수 있는 상점 시스템도 기획했습니다(현재 개발 중).
- **게임 로직 개발**: 플레이어 이동, 사과 생성·낙하와 난이도 상승, 충돌·게임오버, 생존 시간·최고 기록 표시를 Unity와 C# 스크립트로 직접 구현했습니다. 결과물은 WebGL로 빌드해 GitHub Pages에 배포했습니다. 구체적인 구현 방법은 아래 개발 과정에 정리했습니다.
- **직접 만들지 않은 것**: 펭귄 캐릭터 이미지와 움직임 애니메이션, 배경 음악은 Unity Asset Store 등에서 무료로 배포되는 에셋을 내려받아 사용했습니다. 사과 이미지는 이미지 생성 AI로 만들었습니다.

## 개발 과정

### 진행 단계

- **첫 기획과 방향 전환**: 처음에는 격투 게임을 만들려고 했습니다. 공격 히트박스, 시간 제한, 체력 바, 공격 데미지 등을 직접 구현해 보았지만, 캐릭터 이미지와 추가 기능까지 만들어야 할 것이 너무 많아 개발 기간 안에 끝내기 어렵다고 판단했습니다. 그래서 규칙이 단순한 Newton으로 방향을 바꾸고 기획을 새로 정했습니다.
- **플레이어 이동**: A/D 키 또는 ←/→ 방향키를 누르면 펭귄이 좌우로 움직이도록 C# 스크립트를 작성했습니다. 화면 바깥쪽에 보이지 않는 벽을 두어 플레이어가 화면 밖으로 나가지 않게 했습니다.
- **사과 생성·낙하**: 일정 시간마다 화면 위쪽의 무작위 위치에 사과가 생성되어 떨어지도록 구현했습니다. 시간이 지날수록 생성 간격은 짧아지고 낙하 속도는 빨라지게 해서 난이도가 점점 올라가도록 만들었습니다.
- **충돌·게임오버**: Unity에서 펭귄과 사과에 각각 크기에 맞는 히트박스(충돌 범위)를 만들고, 둘이 닿으면 게임오버가 되도록 처리했습니다.
- **UI와 이미지**: 생존 시간과 최고 생존 시간을 화면에 표시해 플레이어가 자신의 기록을 확인할 수 있게 했습니다. 그다음 펭귄·사과 이미지와 애니메이션, 배경 음악을 넣어 화면을 완성했습니다.
- **빌드·배포**: WebGL로 빌드해 GitHub Pages에 올리고, 브라우저에서 플레이되는지 확인했습니다.

## 문제와 해결

### 펭귄 애니메이션이 실행할 때마다 다르게 시작되는 문제

- **현상**: 펭귄 캐릭터에는 평소의 서 있는 모션과 사과에 맞았을 때 엎드려 아파하는 모션 두 가지가 있습니다. 그런데 같은 게임을 실행해도 펭귄이 정상적으로 서 있을 때가 있고 게임 시작부터 엎드린 모션으로 진행될 때가 있어 결과가 일정하지 않았습니다.
- **원인**: Unity의 Animator는 캐릭터가 어떤 모션에서 시작하는지(기본 상태)와 어떤 조건에서 다른 모션으로 넘어가는지(전환 조건)를 정해 두는 곳입니다. Animator 구성 방법을 충분히 이해하지 못한 채 두 모션을 연결해서, 시작 모션과 전환 순서가 의도와 다르게 설정되어 있었습니다.
- **해결**: 인턴십 사수분과 함께 Animator의 모션 연결 구조를 처음부터 다시 점검했습니다. 서 있는 모션을 시작 상태로 두고, 사과와 충돌했을 때만 엎드리는 모션으로 전환되도록 흐름을 다시 구성했습니다.
- **결과**: 이제 게임은 항상 서 있는 모션으로 시작하고, 사과에 맞은 순간에만 아파하는 모션이 재생됩니다. 애니메이션은 모션 파일만 넣는다고 동작하는 것이 아니라, 상태와 전환 흐름을 설계해야 의도대로 움직인다는 것을 배웠습니다.

## 돌아보기

### 배운 점

이 프로젝트 전까지는 게임을 처음부터 끝까지 혼자 만드는 일이 막연하게 느껴졌습니다. 하지만 직접 주제를 정하고 처음 계획이 기간 안에 어렵다고 판단했을 때 방향을 바꾸고 기능을 하나씩 쌓아 웹에 공개하기까지 전 과정을 스스로 진행하면서 **혼자서도 프로젝트를 끝까지 이끌어 갈 수 있다**는 자신감을 얻었습니다. 특히 모든 것을 한 번에 만들려고 하기보다 할 수 있는 범위를 정하고 작은 단계로 나누어 하나씩 완성해 나가는 것이 중요하다는 것을 느꼈습니다.

### 아쉬운 점

아직 게임을 완전히 완성하지 못했습니다. 기본 플레이는 동작하지만 기획했던 사과 스킨 상점은 개발 중인 상태로 남아 있어 이후에 마무리하려고 합니다.

또한 펭귄 애니메이션 문제를 혼자 해결하지 못하고 사수분의 도움을 받아 해결했습니다. 도움을 받으며 원인을 이해할 수 있었던 것은 좋은 경험이었지만 앞으로는 문제가 생겼을 때 공식 문서와 자료를 찾아보며 원인을 직접 분석하고 스스로 해결할 수 있는 능력을 기르고 싶습니다.
