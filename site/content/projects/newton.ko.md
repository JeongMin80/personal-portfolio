## Project overview

Newton is a 2D survival game built with Unity and C#. The player controls a penguin, dodges falling apples, and tries to survive as long as possible.

- **Project type:** Individual game project
- **Engine:** Unity
- **Language:** C#
- **Web build:** Unity WebGL, hosted on GitHub Pages

- [Play the game](https://jeongmin80.github.io/unity-game/)
- [GitHub repository](https://github.com/JeongMin80/unity-game)
